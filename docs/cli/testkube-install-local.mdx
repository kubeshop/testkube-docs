## testkube install local

Install Testkube on this machine

### Synopsis

Sets up a Testkube trial in its own cluster inside Docker.
Needs Docker and the license key from your trial email.
The first run takes 5 to 10 minutes. Your own tools and clusters are not changed.

Already have a Kubernetes cluster? To install Testkube there, run:
  testkube init demo

To remove it later:
  testkube uninstall local

```
testkube install local [flags]
```

### Examples

```
  testkube install local
  testkube install local --license <key>
```

### Options

```

  -l, --license string   Testkube license key from your trial email (or set TESTKUBE_LICENSE)
```
