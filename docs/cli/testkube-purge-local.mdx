## testkube purge local

Remove the local Testkube trial

### Synopsis

Deletes the cluster and its settings. Your data in ~/.testkube/data is kept,
so installing again brings back your tests and results.

```
testkube purge local [flags]
```

### Examples

```
  testkube uninstall local
  testkube uninstall local --delete-data
```

### Options

```
      --delete-data   also delete your Testkube data in ~/.testkube/data
  -h, --help          help for local
  -y, --yes           skip the confirmation prompt
```
