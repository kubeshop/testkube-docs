# Working with Results

Testkube provides a number of features to help you troubleshoot failed tests and work with execution results.

## Workflow Health & Flakiness

- [Workflow Health & Flakiness](/articles/workflow-health) evaluates the reliability and stability of your Test Workflows over time, helping you identify flaky workflows.

## Individual Execution Results

- [Logs & Artifacts](logs-and-artifacts) provide the foundation for test execution troubleshooting.
- [Log Highlighting](/articles/log-highlighting) makes it easy to quickly identify key findings in test execution logs.
- [JUnit Reports](/articles/test-workflows-reports) offer comprehensive processing and visualization of JUnit XML reports, providing both summary and detailed views of test results.
- [Resource Usage](resource-metrics) provides insights into resource consumption for test executions.
- [AI Analysis](/articles/AI-test-insights) uses AI to analyze log outputs and pinpoint key findings.

## Aggregated Results - Insights

- [Overview](/articles/test-insights) provides advanced charting and analysis functionality across all your test execution results.
- [Functional Metrics](/articles/functional-metrics-in-insights) chart the pass/fail/error/skip counts and other granular metrics ingested from your JUnit reports.
- [Performance Metrics](/articles/performance-metrics-in-insights) track performance metrics collected from tools like k6, Artillery, and JMeter over time.
- [Resource Metrics](/articles/resource-metrics-in-insights) analyze resource usage trends across executions.
- [Custom Metrics](/articles/custom-metrics-in-insights) capture and chart custom metrics from any workflow step using InfluxDB Line Protocol.

## Status Pages

- [Status Pages](/articles/status-pages) help you expose Testkube results for monitoring.
